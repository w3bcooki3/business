# NYC Storefronts: website concepts

A portfolio of 22 working, static website concepts for New York small businesses. Open `index.html` to see the showcase.

- **Client proposals:** Kowal & Daughter (2 directions plus a proposal cover) and Durán & Hossain Pharmacy (2 directions)
- **Collection:** 18 concepts across restaurants, pharmacies, cafés, bakeries, barbers and juice bars

## Publish on GitHub Pages
1. Create a repository and upload the *contents* of this folder (so `index.html` is at the root).
2. Go to Settings → Pages → Deploy from a branch → `main` / root.
3. Your link will be `https://<username>.github.io/<repo>/`.

Everything uses relative paths, plain HTML, CSS and JavaScript. There is no build step. `.nojekyll` is included.

All businesses, people, addresses and phone numbers are fictional. Photos are hot-linked from Unsplash.
